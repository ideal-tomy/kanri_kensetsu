## はじめに

本書は、当初合意した開発範囲と現状の実装状況を照合し、以下を明確化することを目的とします：

1. **当初合意した機能のうち、確実に納品される範囲**
2. **当初合意になかったが先行実装した機能（追加サービス）**
3. **将来的な追加開発の対象として見える化された機能**
4. **本契約に含まないこと（追加開発の対象）**

両者がこの内容に合意した上で、**Phase A+B+C** の本番開発を開始します。

## 第7部：変更管理プロセス

運用中に発生する追加要望は、以下のフローで対応します。

### 7.1 要望の分類

```
顧客からの要望
   ↓
【判定】
   ├─ a. 既存機能の使い方の質問     → 即答（無料）
   ├─ b. 軽微な調整・マスタ追加     → 月3件まで無料
   ├─ c. 新機能・大幅変更           → 別途見積もり
   └─ d. 緊急対応                   → 営業時間外は別料金
```

### 7.2 c. の場合の対応

1. 「ご要望ありがとうございます」と受領
2. **1営業日以内に概算見積もり**を提示
3. 顧客承認後に着手
4. 完了後、別途請求

### 7.3 月3件枠の運用

月3件を超える「軽微な改善」は：
- **A案**：翌月に繰越して順次対応
- **B案**：1件あたり1〜3万円で当月対応
