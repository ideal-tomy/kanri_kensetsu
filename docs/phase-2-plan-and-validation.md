# Phase 2 PLAN/実装/検証

## Scope
- D-01 進捗管理: `/tasks`, `/api/tasks`, `/api/tasks/[id]`
- E-01 人員ボード: `/personnel`, `/api/assignments`
- E-02 急変更対応: `/api/assignments/[id]/change`, `/api/assignment-changes/[id]/acknowledge`

## 実装内容
- 進捗カードで `着手/中断/完了` を大ボタン更新
- 人員ボードで配置一覧を表示
- 「急に変更する」で変更カード作成
- 「了解しました」で既読カウント反映

## 検証
### 正常系
1. タスク更新で進捗が反映される
2. 急変更ボタンで変更カードが生成される
3. 了解ボタンで既読数が増える

### 異常系
1. 存在しないID更新は404
2. 変更先現場未入力は400
3. 了解時なまえ未入力は400

## 判定
- Phase 2の中核導線（進捗更新/急変更/了解返答）は成立
- リアルタイム同期はプロトタイプ段階（ポーリングなし）
