# テスト用シナリオ｜現場ナレッジ管理ツール v1.1

[docs/完全案.md](完全案.md) §6 のレビューチェックリストを、実際の操作手順に落とし込んだもの。仮ペルソナの4名で、それぞれの目的が30秒〜10秒で達成できることを確認する。

## 前提

- 開発サーバを起動：`pnpm dev`（または `npm run dev`）
- 初期データはインメモリ store（`src/lib/prototype-store.ts`）から読み込まれる。
- 検証は iPhone SE サイズ（375px）と PC（1280px）の2種で行う。

---

## 1. 田中さん（55歳・職人）｜出来高を加算する

**ねらい**：老眼でも、3秒で「今日どこに行くか」「全体の進み具合」がわかること。

1. `/` を開く。
2. 各現場カードに進捗バー、今日いる人、やってる/とまってる件数が表示されているか確認。
3. 「今日のしごと」をタップ → `/tasks` に遷移。
4. 「外壁ボード貼り」のカードで `[+1]` を3回タップ。
5. 数値が `21 / 35 枚（60%）` に変わり、バーがオレンジに伸びることを確認。
6. `[+10]` を長押しすると `-10` の減算になることを確認。
7. 「数値で入れる」をタップし `5` を入力 → `これでOK` → 数値が `26 / 35 枚` になる。

**合格基準**：3タップ以内で出来高が加算される。完了時は `26 / 35` が `35 / 35`（100%）になり、緑バーと祝福アニメが出る。

## 2. 佐藤さん（42歳・現場監督）｜中断理由を残す

**ねらい**：天候・資材・人手のいずれかを1タップで残せる。

1. `/tasks` を開く。
2. 「外壁ボード貼り」の `[中断]` をタップ。
3. 中断理由モーダルが開く（4択）。
4. `[雨]` をタップ。
5. カードの状態が「とまってる」に変わり、`とまってる理由：雨` と表示される。

**合格基準**：理由つきで中断状態に遷移し、後の検索（「雨」「中断」）で当該タスクがヒットする。

---

## 3. 鈴木さん（38歳・人員管理者）｜週の配置を10秒で把握

**ねらい**：個別連絡なしに、今週の配置を1画面で把握できる。

1. `/personnel` を開く。
2. PC 画面（1280px）で表示。週カレンダー（縦＝現場、横＝月〜日）が出ることを確認。
3. 「Bビル改修 × 月〜火」のセルに `🌙 鈴木さん 夜勤` と表示されているか確認。
4. 「今日」のセルがオレンジで強調されているか確認。
5. `[急に変更する]` をタップ → 「変更カード」セクションに `応援現場 ← ...` の赤枠カードが出る。
6. `[了解しました]` をタップ → カウンタが `+1` される。
7. iPhone SE（375px）で `/personnel` を開く → 「じぶんの今週」が初期表示。
8. プルダウンで担当者を変えると、その人の今週がリスト表示される。

**合格基準**：個別連絡なしで「誰がどこにいる」「夜勤か日勤か」が一目で分かる。

## 4. 山田社長（60歳・経営者）｜全体進捗を入れる

**ねらい**：現場ごとの全体進捗を、PCの大きなボタンだけで更新できる。

1. `/tasks` を開く。
2. 各現場の「現場ぜんたいのすすみぐあい」カードが見える。
3. 「A邸新築」の `[進みぐあいを変える]` をタップ。
4. クイック選択（`32 / 37 / 42 / 47 / 52`）が出るので `47` をタップ。
5. ひとことに「基礎完了。来週から内装」と入れて `[これでOK]`。
6. カードが `47%` に更新され、バーが伸びる。
7. `/` を開くと、ホーム画面のA邸の全体進捗バーも `47%` に同期している。

**合格基準**：1モーダル内で完結し、`siteProgressLogs` に履歴が残る。

---

## 5. 探す画面｜過去事例を発掘

1. `/search` を開く。
2. 「よく探されてる」チップから `#中断` をタップ。
3. 検索結果に「外壁ボード貼り（とまってる理由：雨）」が含まれているか確認。
4. タグ `不具合` をタップ → タスク・日報を横断検索する。

**合格基準**：1タップで過去事例にたどり着ける。
