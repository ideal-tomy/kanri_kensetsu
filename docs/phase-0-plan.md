# Phase 0 PLAN（実装棚卸し）

## 判定基準
- `未実装`: 仕様IDに対応する画面/API/データモデルが存在しない
- `部分実装`: UIのみ、またはモックのみで運用要件を満たさない
- `実装済み`: 仕様IDに対応する導線・データ操作・検証観点が揃っている

## 重大リスク判定
- `P0`: 会社間データ分離破綻、認可欠落、保存不可、主要導線断絶
- `P1`: 通知・検索・急変更など中核業務が未成立
- `P2`: 文言不統一、UI視認性不足、検証不足

## 成果物フォーマット
1. 機能ID単位の棚卸し表（A〜G）
2. 画面ID単位の棚卸し表（S-01〜S-17）
3. ギャップ一覧（優先度/依存関係/着手順）
4. 次Phaseへの入口条件チェック
