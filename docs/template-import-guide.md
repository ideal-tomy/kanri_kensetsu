# 顧客テンプレ取り込み手順

クライアントから現行の報告書フォーマット（Word / Excel / PDF）を受領したあと、本ツールの報告書テンプレとして登録するまでの標準手順です。

## 1. 受領と棚卸し

1. クライアントからファイルと「提出先・提出頻度・必須項目」を受領する。
2. ファイル内の**すべての入力欄**をリスト化する（氏名・日付・チェック項目・写真枠など）。
3. 自動で埋めたい項目に、既存データとの対応を決める（現場名・期間・写真・タスク一覧など）。

## 2. fields JSON の作成

`ReportField` の配列として `report_templates.fields` に保存します。利用できる型は型定義（`src/types/report-template.ts`）を参照してください。

自動入力が必要な項目には、`auto_fill` または `auto_source` を指定します。

| 指定値 | 意味 |
|--------|------|
| `site.name` | 現場名 |
| `today` | 出力基準日（期間終了日を利用） |
| `photos.recent` | 期間内の写真一覧 |
| `photos.by_category.progress` | 進捗報告カテゴリの写真 |
| `tasks.completed` / 一覧表示 | `task_list` フィールドで表現 |

## 3. レイアウト HTML（Handlebars）

1. 顧客書式に近い見出し・余白になるよう HTML と CSS でラフを作る。
2. 差し込み箇所を Handlebars の `{{変数名}}` に置き換える。
3. 一覧部分は `{{#each items}} ... {{/each}}` を利用する（収集データのキーと一致させる）。

## 4. 管理画面への登録

1. 管理画面 `/admin/master/report-templates` で「新規作成」を開く。
2. `fields` を JSON で貼り付け、`レイアウト HTML` にテンプレートを貼り付ける。
3. **保存**（Supabase のサービスロールが設定されている環境でのみ DB 保存が可能）。

サンプル3種はコードに同梱されており、Supabase 未接続でも一覧・PDF 試験が可能です。

## 5. プレビューと PDF 確認

1. `/admin/reports/output` でテンプレ・現場・期間を選ぶ。
2. 「PDF を生成」で実データを取り込んだ結果を確認する。
3. クライアントに見せて体裁を確認し、HTML/CSS を修正する。

## 6. 本番投入

1. 問題なければテンプレを有効のまま運用する。
2. 提出スケジュールが決まっている場合は `submission_schedule` / `submission_day` を設定する（将来の自動送信拡張用）。

所要時間の目安：**1テンプレあたり 4〜6時間**（項目数・レイアウトの複雑さにより変動）。
