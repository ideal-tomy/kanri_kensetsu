# Phase 1 検証結果

## 実装対象
- A-01: `/login` + `/api/auth/login`
- A-02: `/`（ホーム現場一覧） + `/api/sites`
- C-01: `/reports` + `/api/reports` + `/api/reports/parse`

## 正常系
1. 会社コード・なまえ入力で「かいしゃに入る」が成功する
2. 日報入力で「日報をつくる」を押すと構造化プレビューが表示される
3. 「事務所に送る」で日報履歴に反映される

## 異常系
1. 会社コード未入力: 「会社のコードを入れてください」
2. なまえ未入力: 「なまえを入れてください」
3. 日報本文未入力: 「話した内容を入れてください」

## 判定
- Phase 1の最小導線は成立（30秒導線のUI上前提を満たす）
- 本番接続（Supabase Auth/RLS）は次フェーズで実装
