# Phase 1 PLAN（A-01/A-02/C-01）

## 目的
会社コード参加と日報送信を、スマホ前提で最短導線で成立させる。

## Scope IN
- S-01 ログイン（はじめる）
- S-02 ホーム（現場一覧）
- S-04 日報作成（音声/テキスト）
- S-05 日報一覧・詳細
- C-01 日報パーサー（キーワード方式）

## Scope OUT
- 実DB接続（Supabase本番接続はPhase 2以降）
- PDF本生成（Phase 1は印刷用ビューで代替）

## 受け入れ条件
- 田中さん導線: `ログイン -> 現場選択 -> 日報入力 -> 送信` が30秒で完了
- 文言がNGワード規約に違反しない
- 必須入力の不足時に具体的エラーメッセージを返す

## 実装タスク
- UI: `(auth)` `(app)` ルート群と下部ナビ追加
- API: `/api/sites` `/api/reports` `/api/reports/parse` を追加
- DB/RLS: Phase 1はプロトタイプ用メモリストアで代替
- 通知: 送信後にアプリ内おしらせへ保存
- テスト: 手動シナリオ（正常3/異常3）を作成
